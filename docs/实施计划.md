 Android UWB 寻物 Tag 固件实施计划                                                                                      
 Context

 基于 Google 官方 UWB 示例（androidx.uwb / UwbRanging）实现高精度寻物系统：
 - Android 手机 = Controller（发起测距、计算空间坐标）
 - DWM3001CDK = Controlee（BLE OOB 响应 + UWB TWR 响应 + 近距反馈）

 两阶段通信：BLE OOB 参数协商 → UWB TWR 测距（距离 + AoA 方位角）

 关键发现

 现有 QANI 项目 已实现 80% 功能，但使用 Apple NIQ 协议（闭源预编译库 Libs/niq/libniq-*.a），无法用于 Android。

 Android androidx.uwb 使用 FiRa OOB 标准（BLE GATT + UCI 命令），底层 UWB 测距（FiRa TWR）与 QANI 完全一致。

 步骤 2：新增 Android FiRa BLE GATT Service

 创建 Src/Comm/Src/BLE/nrfx/ble_fira_oob.c 和 .h，参考 ble_qnis.c 的实现模式。

 BLE Service 定义：
 - FiRa UWB Service UUID：0x1850（标准 16-bit UUID，待确认是否为 FiRa 规范定义的值；Android UwbRanging sample 使用此
 UUID 用于 OOB）
   - 如果 16-bit 不适用，使用 128-bit UUID
 - 特征 1 — UCI Control Point（Write/Write No Response）：手机→Tag 发送 UCI 命令
 - 特征 2 — UCI Data（Notify）：Tag→手机 返回 UCI 响应和测距结果

 数据格式：标准 UCI 包（3 字节 header：Group ID + Opcode ID + Payload Length），与现有 uci_parser.h 兼容。

 ble_fira_oob.h 核心接口：
 // BLE 收到 UCI 命令时的回调
 void fira_oob_on_uci_command(uint16_t conn_handle, const uint8_t *data, uint16_t len);

 // 发送 UCI 响应/通知到手机
 void fira_oob_send_response(uint16_t conn_handle, uint8_t *data, uint16_t len);

 // 发送测距结果（编码为 UCI RANGING_NOTIFICATION）
 void fira_oob_send_ranging_result(uint16_t conn_handle,
                                    struct fira_twr_measurements *rm);

 步骤 3：新增 BLE→UWB 桥接模块

 创建 Src/Apps/Src/ranging_tag/ranging_tag.c 和 .h，这是核心模块。

 参考 fira_niq.c 的 niq_configure_and_start_uwb() 流程，但用自定义 UCI 解析替代 NIQ 库。

 核心流程：
 手机 BLE Write UCI SESSION_CONFIG
     → ranging_tag_handle_uci_cmd()
     → 解析 UCI SESSION_CONFIG 包体
     → 填充 fira_device_configure_t 结构体
     → 保存到 fira_config_ram
     → 返回 UCI STATUS_OK

 手机 BLE Write UCI START_RANGING
     → ranging_tag_handle_uci_cmd()
     → 调用 fira_niq_app_process_init(false)  [复用 fira_niq.c]
     → 调用 uwbmac_start()
     → 调用 fira_helper_start_session()
     → 返回 UCI STATUS_OK

 UWB 测距完成（回调 report_cb）  [复用 fira_niq.c]
     → 编码为 UCI RANGING_NOTIFICATION 格式
     → 通过 BLE Notify 发送到手机

 手机 BLE Write UCI STOP_RANGING
     → 调用 fira_stop_niq()  [复用 fira_niq.c]

 关键数据结构映射（Android FiRa OOB → fira_device_configure_t）：
 UCI Session Config Params    → fira_device_configure_t
 ─────────────────────────────────────────────────
 Session ID (4 bytes)         → Session_ID
 Device Role (Controller)     → role = 1
 Channel Number (通常 9)      → Channel_Number
 Preamble Code Index (通常 11)→ Preamble_Code
 STS Config (Static)         → STS_Config + Static_STS_IV
 Ranging Method (DSTWR)      → Ranging_Round_Usage
 Multi-Node Mode             → Multi_Node_Mode
 Short Address               → SRC_ADDR[2]
 Peer Address                → DST_ADDR[2]

 步骤 4：添加蜂鸣器驱动（可选但推荐）

 创建 Src/HAL/Inc/HAL_buzzer.h 和 Src/HAL/Src/nrfx/HAL_buzzer.c。

 DWM3001CDK 无板载蜂鸣器，需外部连接：
 - 使用空闲 GPIO（推荐 P0.03 或 P0.13）
 - PWM 控制有源蜂鸣器

 接口：
 void buzzer_init(uint32_t gpio_pin);
 void buzzer_beep(uint32_t duration_ms);
 void buzzer_distance_alert(uint32_t distance_cm); // <1m 间歇蜂鸣

 在 report_cb 中集成（fira_niq.c:306-328 附近）：
 - 距离 < 1m：LED 红灯 + 快速蜂鸣
 - 距离 1~3m：LED 绿灯 + 慢速蜂鸣
 - 距离 > 3m：LED 绿灯

 步骤 5：组装 main.c

 新 main.c 基于 QANI 简化版：

 int main(void) {
     // 1. 硬件初始化
     BoardInit();
     init clocks, LFCLK, NVM cache, persistent time

     // 2. 日志（可选，调试用）
     create_log_processing_task();

     // 3. 创建 Ranging Tag 任务
     CreateRangingTagTask();  // 内部：初始化 uwbmac，创建 Qani task + signal

     // 4. 启动 BLE 广播（FiRa UWB Service UUID）
     char adv_name[32];
     snprintf(adv_name, sizeof(adv_name), "UWB-Tag (%08X)", NRF_FICR->DEVICEADDR[0]);
     ble_init(adv_name);  // 需修改 ble.c 添加 FiRa OOB Service 初始化

     // 5. 启动 FreeRTOS
     qos_start();
     for (;;) { APP_ERROR_HANDLER(NRF_ERROR_FORBIDDEN); }
 }

 验证流程

 1. 编译验证：cd BuildOutput/AndroidRangingTag/FreeRTOS/DWM3001CDK/Debug && make -j
 2. 烧录验证：用 J-Link 烧录到 DWM3001CDK，确认 BLE 广播名称出现
 3. BLE OOB 验证：手机安装 UwbRanging sample app，确认能发现并连接到 Tag
 4. UCI 命令验证：在串口日志中确认收到 SESSION_CONFIG 和 START_RANGING
 5. UWB 测距验证：确认串口输出 JSON 测距结果 {"Block":0, "results":[{"Addr":"0x0001","Status":"Ok","D_cm":150,...}]}
 6. 近距反馈验证：距离 < 1m 时确认 LED 红灯亮起，可选蜂鸣器响起

 风险与注意事项

 1. BLE UUID 确认：FiRa OOB Service UUID 需参考 FiRa UCI over GATT 规范（可能在 Android 源码 packages/modules/Uwb
 中确认）。不影响功能开发，后续可调整。
 2. Android 手机兼容性：需 UWB 硬件支持（Samsung S23+/Ultra、Pixel 8 Pro 等），国产手机需等 UWB 普及。
 3. AoA 支持：DWM3001CDK 需 AoA 天线阵列才能提供方位角。检查 AOA_CHIP_ON_NON_AOA_PCB 标志。
 4. NIQ 库不兼容：Apple NIQ 库（libniq-*.a）完全不用，不构成阻碍。
 5. 电源优化：Tag 场景需电池供电，后续可能需要添加低功耗模式（vPortSuppressTicksAndSleep）。
